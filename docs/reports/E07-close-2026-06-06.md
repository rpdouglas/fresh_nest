## Architecture Notes

- **`whileInView` introduced** — first below-fold section. Heading and grid use separate `motion.div` wrappers both with `viewport={{ once: true, margin: '-50px' }}`. All above-fold components (Hero, TrustBar) correctly use `animate` on mount.
- **`ServiceIcon` switch component** — exhaustive switch over `ServiceType` union. TypeScript infers exhaustiveness; no default branch needed. Icons inherit `currentColor` so they auto-invert on the commercial card without conditional logic.
- **`h-full` on `<article>`** — grid stretches cards to equal row height. `flex-1` on the description paragraph pushes all CTAs to the card bottom regardless of description length.
- **`serviceTitle` variable** — `t(card.labelKey)` cached once per card iteration and passed to both `<h3>` and `aria-label` interpolation, avoiding a double `t()` call.
- **Background:** `bg-cream` alternates correctly after QuoteCalculator's `bg-warm-white`. Pattern: `warm-white → cream → warm-white → cream`.
- **Inverted CTA:** outlined white (`border border-white text-white`), fills white on hover → `text-slate-brand`. Matches the established "secondary on dark" pattern.

## Architecture Notes

- **`galleryData.ts` as the single source of truth:** `GALLERY_PAIRS` and `FEATURED_PAIRS` are consumed by `GalleryPreview`, `Gallery`, and `Lightbox` from one location. E27 sets `beforeSrc`/`afterSrc` paths here; no component changes needed.
- **`GalleryImage` null guard:** Renders `<img>` when `src` is a string; renders a `bg-slate-pale` placeholder div with `role="img"` and `aria-label` when `src` is null. Transparent to the E27 photography pass.
- **Lightbox portal:** Renders to `document.body` via `createPortal`. `AnimatePresence` in `Gallery.tsx` wraps the conditional render — React's virtual DOM lifecycle drives exit animations correctly regardless of DOM portal position.
- **Focus management:** Close button receives `autoFocus` via `closeRef.current?.focus()` in `useEffect`. Trigger element reference stored in `triggerRef` at open time; focus restored on close with 200ms delay (matches exit animation duration).
- **`services.${serviceKey}.title` reuse:** Alt text interpolation consumes existing service title i18n keys — no new translation strings needed for alt text.
- **Background:** `bg-cream` GalleryPreview alternates correctly after RecurringCTA's `bg-warm-white`. Homepage sequence: `warm-white → cream → warm-white → cream → warm-white → cream`.
- **E27 handoff:** Set `beforeSrc` and `afterSrc` in `GALLERY_PAIRS` to real WebP paths (e.g., `'/images/gallery/kitchen-deep-before.webp'`). Add explicit `width` and `height` attributes to `GalleryImage`'s `<img>` tag at that time for CLS performance.

2. **Centralized Firestore Converters & Collection Helpers**:
   - Created `packages/shared/src/firebase/converters.ts`.
   - Implemented `FirestoreDataConverter` implementations for all 7 primary collections: `bookings`, `jobs`, `staff`, `reviews`, `payRates`, `checklistTemplates`, and `auditLog` (mapping to `AuditEntry`).
   - Implemented `cleanUndefined` helper to automatically strip `undefined` fields from document payloads during writes (`toFirestore`).
   - Implemented robust recursive `toDate` and `toDateOrNull` functions to map Firestore `Timestamp` objects (as well as plain-object shapes) to standard Javascript `Date` objects on reads (`fromFirestore`).
   - Provided centralized collection factory helper functions (e.g. `bookingsCollection(db)`, `jobsCollection(db)`, etc.) that return fully typed collection references.

3. **Application Refactoring**:
   - Refactored `apps/customer` components and hooks (`useBookings`, `useStaff`, `usePayRates`, `useChecklistTemplates`, `useAuditLogs`, `useOperationsDashboard`) to use the new typed helpers, completely removing all manual `Timestamp` casts and `instanceof Timestamp` checks.
   - Refactored `apps/fsm` hooks and context providers (`StaffAuthProvider`, `OfflineUploadProvider`, `useShifts`, `useMyAssignedShifts`, `useJob`, `useNotifications`, `JobPage`, `MyJobsPage`, `ProfilePage`, `TermsConsentOverlay`) to adopt the helper factory collections.

4. **Testing Mocks & Verification**:
   - Updated and normalized Firestore mocks in test suites (`useAuditLogs.test.ts`, `useStaff.test.ts`, `TermsConsentOverlay.test.tsx`, `useStaffAuth.test.tsx`, `JobPage.test.tsx`, `useNotifications.test.tsx`, `ProfilePage.test.tsx`) to mock collection-query mappings that automatically attach the appropriate converter configuration and invoke `fromFirestore` on returned data objects.

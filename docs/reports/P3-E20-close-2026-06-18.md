## Required Manual Operator Step (Before Go-Live)

1. Go to **Firebase Console → App Check → Apps**
2. Register the customer web app with its ReCaptcha V3 site key
3. Register the FSM web app with its ReCaptcha V3 site key
4. **Enable enforcement** on: Firestore, Cloud Functions, Storage
5. Add `VITE_RECAPTCHA_SITE_KEY` to both apps' Hosting environment configs (Firebase Hosting → Environment Variables)

Until enforcement is enabled in the console, App Check is present in the client code but not enforced server-side.

## Architecture Notes

### `stripePromise` singleton
`loadStripe()` is called at module level outside the component function. This prevents a new Promise being created on every render and ensures `window.Stripe` (set by test `addInitScript`) is picked up before the module runs.

### `isLoadingPayment` derived state
Rather than managing a separate boolean, loading state is derived: `currentStep === 3 && !clientSecret && !paymentInitError`. This avoids synchronous `setState` inside the `useEffect` body, which ESLint's `react-hooks/set-state-in-effect` rule would flag.

### `BookingStep4Handle.submitPayment()`
`BookingStep4` is a `forwardRef` component. `submitPayment()` is exposed via `useImperativeHandle`. The method:
1. Calls `elements.submit()` (validates PaymentElement)
2. Calls `stripe.confirmPayment({ elements, redirect: 'if_required', confirmParams: { return_url } })`
3. Returns the `paymentIntent.id` on success (`'requires_capture'` status for pre-auth), or `null` on failure with the error shown in the component's `role="alert"` block

### Stripe namespace types (v22)
`Stripe.Event` and `Stripe.PaymentIntent` are not accessible from the CJS default import in stripe v22 (`StripeConstructor` namespace only exports `type Stripe`). The webhook handler uses a local `StripeEventLike` shape type instead.

### HST
13% ON applied at launch in both the client price display and the `createPaymentIntent` callable. QC rate (14.975%) requires billing address province detection — flagged as TBD comment in `functions/src/index.ts`.

### 3DS redirect
`stripe.confirmPayment` uses `redirect: 'if_required'`. The `return_url` points to `/thank-you`. For cards requiring 3DS, the user is redirected; the booking state on return from 3DS is not yet handled (out of scope for this epic). Non-3DS cards resolve in-page.

### Environment variables required for production
- `STRIPE_SECRET_KEY` — Firebase Functions secret (already used by `onBookingCancelled`)
- `STRIPE_WEBHOOK_SECRET` — Firebase Functions environment variable for webhook signature verification
- `VITE_STRIPE_PUBLISHABLE_KEY` — Firebase Hosting environment variable (must be added to `.env.production` or hosting config)

### Stripe Dashboard setup (manual)
1. Set webhook endpoint to: `https://us-central1-freshnest-aa51e.cloudfunctions.net/stripeWebhookHandler`
2. Subscribe to events: `payment_intent.amount_capturable_updated`, `payment_intent.succeeded`, `payment_intent.payment_failed`
3. Copy the webhook signing secret → set as `STRIPE_WEBHOOK_SECRET` in Firebase Functions config

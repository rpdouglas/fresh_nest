**Date:** 2026-06-07 | **Phase:** 2

## Summary

Implemented the `/faq` route as a standalone page using Strategy 2 — Single `FaqPage` component with static data array. All 10 FAQ items are driven by `FAQ_ITEMS: FaqItem[]` (id + qKey + aKey), with answers expanded via a multi-open `Set<number>` state. AnimatePresence with `height: 'auto'` provides smooth accordion animations. Chevron rotates 180° on open. React 19 native `<title>` + `<meta>` hoisting provides per-page SEO. The App.tsx `PlaceholderPage` for `/faq` is replaced with `<FaqPage />`.

## Architecture Notes

- **Multi-open accordion:** `useState<Set<number>>(new Set())` — each item tracked by index. Unlike a single-open accordion, `Set` allows any number of panels open simultaneously. Toggle function returns a new `Set` (immutable pattern required by React state).
- **`AnimatePresence initial={false}`** — prevents all closed items from animating on first render. Only toggles after user interaction trigger animations.
- **`height: 'auto'` in Framer Motion** — supported natively in Framer Motion v12. Requires `overflow-hidden` on the animated element; without it, content bleeds during the exit animation.
- **`aria-expanded` + `aria-controls`** — each button sets `aria-expanded={isOpen}` and `aria-controls={faq-answer-${item.id}}`. The `motion.div` answer panel carries the matching `id`. This wires the button/panel relationship for screen readers per ARIA accordion pattern.
- **React 19 head hoisting** — `<title>` and `<meta name="description">` as JSX children; React 19 hoists to `<head>`. Consistent with LocationPage and LocationsOverview patterns.
- **`t('phone')` reuse** — the phone number string is defined once in `common.phone` (shared across Navbar, Footer, FaqPage CTA). No duplication.

## Architecture Notes

- **`LocationConfig.calloutKey?: string`** — optional prop; when present, `LocationPage` renders a `bg-slate-pale` callout band using `config.calloutKey != null` guard (TypeScript narrowing from `string | undefined` to `string` before the `t()` call). Only Akwesasne and Snye QC set this prop.
- **`t(\`services.${service}.title\`)`** — reuses the existing `services.*` i18n namespace for service chip labels. TypeScript infers the template literal as `string`; react-i18next accepts `string` keys. No new service name translations needed.
- **React 19 head hoisting** — `<title>` and `<meta name="description">` are rendered as JSX children in a Fragment. React 19 hoists them to `<head>` in the browser. Initial HTML served by Firebase still has the static `<title>` from `index.html`; Google (which renders JS) will see the dynamic title. Acceptable for Phase 2 local SEO.
- **Google Maps iframe** — `maps.google.com/maps?q=${config.mapQuery}&output=embed` format; no API key required. `loading="lazy"` defers iframe load until near viewport. `referrerPolicy="no-referrer-when-downgrade"` is standard for third-party iframes. Phase 4 can upgrade to Maps Embed API with lat/lng coordinates for precise pin placement.
- **Route fix** — `/locations/cornwall` (the old PlaceholderPage slug) is removed from App.tsx and replaced by `/locations/cornwall-on` per the master plan spec. The old slug had no live links pointing to it (footer links used the i18n key but didn't specify the slug explicitly).
- **Service availability assumption** — the 5 service lists in `locationData.ts` are Phase 2 assumptions. Cornwall ON: full suite (all 6); Akwesasne: standard, deep, moveout, postconstruction; Snye QC: standard, deep, moveout; Long Sault: standard, deep, moveout, airbnb; Morrisburg: standard, deep, moveout. **These must be confirmed by the business owner before launch.**
- **`aria-hidden` on "View details →"** — the entire location card is a `<Link>` with `<h2>` heading providing the accessible name. The "View details →" span is decorative within the link — `aria-hidden="true"` prevents redundant announcement.

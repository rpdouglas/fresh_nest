## Summary

Implemented the bilingual Recurring Cleaning Section as the fifth homepage section. Three frequency cards (Weekly 20% off, Biweekly 15% off, Monthly 10% off) in a responsive 1→3 column grid. The Biweekly card uses inverted `bg-slate-brand` styling as the visually prominent recommended option — matching the Commercial card inversion pattern from ServicesGrid. Each card has its own CTA pre-populating the booking form with the selected frequency via URL params. Zero Firestore operations — purely presentational. Frequency labels reuse existing `quote.frequency.*` i18n keys from E06.

## Architecture Notes

- **Key reuse:** `quote.frequency.weekly/biweekly/monthly` labels from E06 are consumed directly in `RecurringCTA.tsx` via `t(\`quote.frequency.${card.freq}\`)` — no duplicate translation strings introduced.
- **Inversion pattern:** Biweekly card uses the same `bg-slate-brand` / outlined-white-CTA inversion established in ServicesGrid's Commercial card. Consistent visual language for "recommended/primary" options.
- **Discount badge:** `bg-slate-pale text-slate-brand` on standard cards; `bg-white text-slate-brand` on inverted card — white fill inverts to `slate-pale` equivalent on the dark background.
- **`whileInView` scroll-reveal:** Heading block and card grid use separate `motion.div` wrappers with `viewport={{ once: true, margin: '-50px' }}`, consistent with ServicesGrid.
- **Background:** `bg-warm-white` alternates correctly after ServicesGrid's `bg-cream`. Pattern so far: `warm-white → cream → warm-white → cream → warm-white`.
- **FR CTA convention:** `"Réserver — {{freq}}"` uses an em-dash separator between verb and object, following established FR typographic convention for this project.

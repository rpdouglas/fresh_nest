## PIPEDA Compliance
`maskAllInputs: true` ensures booking form fields (name, email, phone, address) are never captured in Sentry Replay recordings. `networkDetailAllowUrls: []` prevents request/response body logging. ✅

## Manual Operator Steps Required (not automatable)
1. **Create Sentry project** at sentry.io — get DSN
2. **Add GitHub Secrets:**
   - `VITE_SENTRY_DSN` — browser DSN (customer + FSM)
   - `SENTRY_AUTH_TOKEN` — for source map uploads
   - `SENTRY_ORG` — Sentry org slug
   - `SENTRY_PROJECT` — Sentry project slug
3. **Add Firebase Secret:** `SENTRY_DSN` via `firebase functions:secrets:set SENTRY_DSN`
4. **Create GCP Uptime Check** on https://lilypad-freshnest.web.app (Cloud Monitoring → Uptime Checks)
5. **Create GCP Alert Policy** on Cloud Functions error rate > 1% over 5 min window
6. **Configure UptimeRobot** (optional, free-tier external monitor) pointing at the same URL

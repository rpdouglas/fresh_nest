## 1. Overview & Strategy Deployed
We implemented **Strategy 1: Full-safety integration** from the [F07_PLAN.md](file:///workspaces/fresh_nest/docs/plans/F07_PLAN.md).

This strategy guarantees that personal unavailable time blocks and recovery group commitments are transactionally respected for staff members like Mike (P9) while providing operational visibility and overrides for managers like Sarah (P12) without compromising privacy.

Key design criteria achieved:
1.  **Shift Board Hiding:** Shifts that overlap with the staff member's blocked windows (recurring or one-time) are completely hidden from the FSM Shift Board (absent, not greyed out).
2.  **Backend Verification:** Backend `executeClaimJob` Cloud Function transactionally checks blocked windows and aborts the claim if a conflict occurs, returning a mapped `BLOCKED_WINDOW_OVERLAP` error.
3.  **Admin Override Warning:** Intercepts admin manual cleaner assignments that conflict with blocked windows, prompting Sarah for a mandatory override explanation.
4.  **Privacy Protection:** The labels of the blocked windows (e.g. "Recovery meeting") are kept strictly confidential and are never exposed in the admin panel or to other employees.
5.  **Audit Trail:** Saves override events to `/auditLog` under `overrideType: "blocked_window_overlap"`.

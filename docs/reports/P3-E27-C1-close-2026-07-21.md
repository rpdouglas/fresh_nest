## Work Done

1. **`OnboardingSequenceGuard`** (new): inserted into the router tree between `ProtectedRoute` and `FsmLayout` in `apps/fsm/src/App.tsx`. Renders exactly one step at a time from a fixed priority list — Language Selection → Employment Agreement → Background Check Consent → Platform Terms → Emergency Contact → the real FSM app (`Outlet`). Fixes a real pre-existing bug where `BackgroundCheckConsentScreen` (z-60) could render on top of `LanguageSelectionOverlay` (z-50) before a language was ever chosen.
2. **Two new screens**: `EmploymentAgreementScreen.tsx` (scrollable agreement text, typed-name signature, checkbox, client-observed IP via the existing ipify.org pattern) and `EmergencyContactScreen.tsx` (name/relationship/phone). Both modeled on `TermsConsentOverlay`'s UI shell.
3. **Reused unchanged**: `BackgroundCheckConsentScreen` and `TermsConsentOverlay` (P3-E27-B2/pre-existing) gained an additive, optional `stepLabel` prop only — their internal logic, tests, and Firestore-write behavior are untouched.
4. **Removed** the three ad-hoc overlay mounts from `FsmLayout.tsx` — onboarding state is now owned entirely by `OnboardingSequenceGuard`.
5. **Schema**: added `employmentAgreement` and `emergencyContact` (both `| null`, top-level per user decision) to the `Staff` type, `staffConverter`, `onStaffRegistered`'s initialization, and `docs/firestore-schema.md`.
6. **`firestore.rules`**: added both new fields to the `staff/{staffId}` self-service `hasOnly()` allowlist — both are fully employee-writable with no admin-only sub-fields, so no nested-diff logic was needed (unlike `backgroundCheck` in B2).
7. **i18n**: 17 new keys across `fsm.compliance.employmentAgreement.*`, `fsm.compliance.emergencyContact.*`, and `fsm.compliance.onboarding.stepLabel`, full EN/FR parity.
8. **Returning-employee handling**: the guard shows no "Step X of 4" label when re-prompting an already-onboarded employee for a terms-version bump (detected via `emergencyContact` already being non-null), vs. "Step 3 of 4" during a fresh employee's first pass through the sequence.

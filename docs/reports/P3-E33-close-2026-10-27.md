## What shipped
- **New building blocks** (`components/admin/ui/`):
  - `useDialogBehavior`: Escape closes, Tab and Shift+Tab stay in the dialog, focus moves in on open and back to the opener on close, page scroll is locked.
  - `AdminDialog`: keeps each modal's own overlay and panel classes and **appends only `max-md:` classes**. On phones it is full screen with a sticky ✕ (`md:hidden`).
  - `ConfirmDialog`: a centred confirmation. "Keep booking" comes first and gets focus.
  - `dialogClasses.PHONE_STICKY_ACTIONS`: pins the action row to the bottom on phones.
- **`AdminSectionNav` + `adminTabs`:**
  - one `ADMIN_TABS` list;
  - the desktop tab strip with byte-identical classes;
  - a sticky phone "Section" select;
  - the section is kept in `?tab=` (unknown values fall back to Bookings).
- **`AdminPage`:**
  - uses `useSearchParams` for the tab;
  - outer `<main>` is now `<div>` (one `<main>` landmark);
  - compact phone header (H1 `text-3xl`, welcome line and email hidden, one-row profile with Sign Out).
- **`Layout`:** on `/admin`, the Footer, CookieBanner and InstallPrompt are wrapped in `max-md:hidden`.
- **Modals:**
  - `AdminBookingModal`, `RegisterStaffModal`, `ExportRecordModal` and `OverrideModal` are on `AdminDialog`;
  - the first three have sticky action rows;
  - `OverrideModal`'s overlay now scrolls.
- **Confirmation:** `BookingDetailPanel` asks before a status change to **Cancelled** or **Confirmed**, naming the client and date (EN/FR).
- **Copy and markup fixes:**
  - lead source shows its label (reuses the existing `admin.bookings.modal.leadSourceOptions.*`);
  - "Avg Job Duration" reads `0.0 hrs`, not `0.0 0 hrs`;
  - the analytics error has its own title;
  - booking rows use `<Fragment key>`, not `<tr className="contents">`;
  - dispatch date controls wrap on phones.
- **Harness** (`apps/customer/e2e-admin/`, `npm run test:admin-visual`):
  - emulator seed, Firebase swap, Playwright spec;
  - 11 desktop screenshots at 1280×900 and 5 phone checks at 390×844 / 360px.
  - It runs locally only; it needs Java and the emulators.

## Deviations from the plan
1. **`colSpan` stays 5.** Setting it to 6 widened the expanded panel on desktop, which breaks the "desktop unchanged" constraint. A code comment explains this. Revisit in phase 2, when the bookings table becomes cards on phones.
2. **Lead-source labels:** reused the existing `leadSourceOptions` keys instead of adding `admin.leads.*`, so there are no duplicate strings.
3. **Dispatch row wrap (`max-md:flex-wrap`):** added because the date controls overflowed at 360px.
4. **Harness hardening:**
   - fonts blocked, fixed clock, charts masked;
   - scroll and mouse reset, animations disabled;
   - `maxDiffPixelRatio: 0`.
   Baselines were re-captured from the before-code (commit `9a9209e`) with these settings.

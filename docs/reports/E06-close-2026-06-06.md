# E06 Close Report — Instant Quote Calculator
**Date:** 2026-06-06 | **Phase:** 1

---

## Summary

Implemented the bilingual Instant Quote Calculator as the third homepage section. Three segmented button groups (Property Size × 5, Service Type × 5, Frequency × 4) drive a reactive price display — no form submission, no account required. Prices update instantly on every selection. Defaults (3–4 Bed + Standard + Biweekly) show a price range at zero taps. The "Book Now" CTA passes selections to `/booking` via URL params for E15 pre-population.

## Architecture Notes

- **`quotePricing.ts`** is isolated from UI — all pricing constants and the `calculateQuote()` pure function live here. Easily replaced with a Firestore-backed config before launch without touching the component.
- **Discriminated union** `QuoteResult = { type: 'range' } | { type: 'commercial' }` — TypeScript narrows correctly in JSX without non-null assertions.
- **`Quote*` type prefix** — avoids collision with the existing `ServiceType` export in `src/types/index.ts`.
- **`useMemo` on `bookingHref`** — URL construction runs only when selections change, not on every render.
- **`aria-live="polite"` result panel** — screen readers announce price changes without interrupting other activity.
- **Background:** `bg-warm-white` alternates correctly after TrustBar's `bg-cream`.

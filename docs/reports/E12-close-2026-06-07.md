## Architecture Notes

- **Language sort — derived value, no state:** `const sorted = [...STATIC_REVIEWS].sort(...)` runs on every render from `i18n.language`. No `useState`, no `useEffect`. When the user toggles language, the component re-renders and the new sort order is applied instantly. Stable partial sort: same-language reviews float top; relative order within each group is preserved.
- **`ReviewCard` as a sub-component:** Extracted to keep the `Reviews` function body readable and to isolate the `motion.article` variants usage. Not a separate file — single-file pattern consistent with `StarRating` (private, component-local).
- **Carousel → grid layout transition:** `flex gap-5 overflow-x-auto snap-x snap-mandatory pb-4` on mobile; `md:grid md:grid-cols-2 md:overflow-visible md:pb-0 lg:grid-cols-3` overrides at md+. Card width `w-[min(18rem,85vw)]` on mobile; `md:w-auto md:shrink` releases the fixed width for grid layout. The `pb-4` on mobile prevents card box-shadows from being clipped by `overflow-hidden` (the `overflow-x-auto` clips vertical overflow too — `pb-4` adds clearance below card shadow).
- **Phase 3 readiness:** `Review` interface exports from `src/lib/reviewsData.ts`. Phase 3 `useApprovedReviews()` hook will return `Review[]` (filtered by `approved: true` in the Firestore query). Replacing `STATIC_REVIEWS` with the hook result in `Reviews.tsx` requires one line of change — the language sort, card rendering, and i18n keys are untouched.
- **Background sequence (10 sections):** `warm-white → cream → warm-white → cream → warm-white → cream → warm-white → cream → warm-white` (Hero→TrustBar→QuoteCalc→ServicesGrid→RecurringCTA→GalleryPreview→HowItWorks→MeetTheTeam→Reviews).
- **Placeholder reviews note:** Five static reviews are representative placeholders — not real client reviews. All five will be replaced with live Firestore data in E22 (Phase 3 live reviews integration). Names, locations, and texts are plausible but fictional.

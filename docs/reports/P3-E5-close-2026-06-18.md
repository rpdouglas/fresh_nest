## Changes Made

### `.github/workflows/firebase-deploy.yml`
- Added `Security audit` step (`npm audit --audit-level=high`) immediately after `npm ci`, before the build. High-severity CVEs now block every production deploy.

### `.github/workflows/firebase-preview.yml`
- Added same `Security audit` step for PR preview builds.
- Added `id: deploy-customer-preview` to the customer preview deploy step to expose the `details_url` output.
- Added `Lighthouse CI` step (`treosh/lighthouse-ci-action@v11`) after preview deploy: audits homepage and `/booking` of the preview URL; uploads results to temporary public storage and posts a report link as a PR comment automatically.

### `.github/dependabot.yml` (new)
- Weekly PRs for all four npm workspaces (root, `apps/customer`, `apps/fsm`, `functions`) and GitHub Actions, scheduled Monday.

### `.github/workflows/codeql.yml` (new)
- Runs CodeQL `javascript-typescript` with `security-and-quality` queries on every PR and push to main, plus a weekly Monday 08:00 UTC scheduled scan. Results surface in the GitHub Security tab.

### `docs/decisions/ADR-012-rollback-procedure.md` (new)
- Documents the step-by-step rollback procedure for Firebase Hosting (one-click in Firebase Console) and Cloud Functions (git checkout + redeploy). Accepted.

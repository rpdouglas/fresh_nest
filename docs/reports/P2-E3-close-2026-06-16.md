## 1. Overview
Epic **P2-E3** automatically sends an SMS notification to the customer when their assigned cleaner checks in to a job. This real-time update reduces customer anxiety about arrival windows, establishes a premium level of service communication, and offers real-time status visibility for tight turnaround situations (like Airbnb check-ins).

---

## 2. Work Done

### A. Firebase Cloud Functions
- **Check-in Listener (`onJobUpdatedTrigger`)**: Extended the trigger in [index.ts](file:///workspaces/fresh_nest/functions/src/index.ts) to detect cleaner check-in events.
  - Monitors job document updates.
  - Specifically filters for the check-in transition where:
    - Status transitions from `'assigned'` or `'acknowledged'` to `'in_progress'`.
    - `checkedInAt` changes from a null value (`null` or `undefined`) to a valid timestamp.
- **Parent Booking Retrieval**: Automatically queries the parent booking using `bookingId` from the `bookings` collection to retrieve the customer's selected language (`'en'` or `'fr'`).
- **Cleaner Profile Retrieval**: Queries the assigned staff member from `staff/{uid}` to fetch their `firstName`.
- **Dynamic Fallbacks**: 
  - If the cleaner's first name is missing or the staff profile is not found, the SMS uses a localized generic term: `"your cleaner"` in English, and `"votre préposé(e)"` in French.
  - If the parent booking is not resolved, it defaults to English.

### B. SMS Infrastructure & Localization
- **Twilio Dispatcher (`sendOnMyWaySms`)**: Added helper function to [sendSms.ts](file:///workspaces/fresh_nest/functions/src/sendSms.ts) that instantiates the Twilio client, normalizes the recipient's phone number, and dispatches the text message.
- **SMS Templates (`onMyWaySms`)**: Added localized messaging templates to [smsTemplates.ts](file:///workspaces/fresh_nest/functions/src/smsTemplates.ts):
  - **EN:** *"Fresh Nest Co.: Your cleaner {cleanerName} is on the way! Estimated arrival is near your scheduled start window. (613) 935-3555"*
  - **FR:** *"Fresh Nest Co. : Votre préposé(e) {cleanerName} est en route ! Arrivée prévue près de votre plage de début programmée. (613) 935-3555"*

### C. Duplicate Prevention
- Executed strict state-transition checking on `checkedInAt` and `status` values inside the trigger. Because `checkedInAt` is only written once upon check-in, subsequent updates (such as checklist updates or photo uploads) will fail the `!before.checkedInAt && after.checkedInAt` guard. No new database fields were invented, fully respecting the Firestore schema constraints.

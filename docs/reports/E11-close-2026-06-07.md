## Architecture Notes

- **`TeamAvatar` — null-safe pattern:** Follows `GalleryImage.tsx` (E09) pattern. `photoSrc: string | null` on each `TeamMember`; E27 sets real paths with zero component changes. When `src` is null and `initials` is a non-empty string, renders initials in `font-display text-4xl text-slate-brand` on `bg-slate-pale`. When `initials` is empty string (placeholder cleaner), renders a person-silhouette SVG — avoiding fake initials for an unnamed team member.
- **`aria-hidden` on avatar placeholder:** The avatar div is `aria-hidden="true"` in all cases — the card `<h3>{member.name}</h3>` already announces the name to screen readers. The avatar adds no new information.
- **Callout `text-charcoal` (not `text-slate-brand`):** Pre-identified in Phase A plan. `text-slate-brand` (`#5b7e8f`) on `bg-slate-pale` (`#d6e5ec`) ≈ 3.0:1 — below 4.5:1 WCAG AA. `text-charcoal` on `bg-slate-pale` ≈ 9.0:1 ✓. `text-slate-brand` is still used on the checkmark icon (decorative, `aria-hidden`) and the Book Now link (underline provides secondary indicator, not colour-only).
- **Placeholder names:** `"Ryan D."` (owner — real) and `"Cleaner Name"` (generic — placeholder). The second card uses `initials: ''` to trigger the person-silhouette avatar rather than a meaningless initial. These values are replaced in E27 before launch.
- **Background sequence:** `warm-white → cream → warm-white → cream → warm-white → cream → warm-white → cream` (Hero→TrustBar→QuoteCalc→ServicesGrid→RecurringCTA→GalleryPreview→HowItWorks→MeetTheTeam).
- **Consistent cleaner language:** "nettoyeur attitré" appears in: HowItWorks Steps 2 & 3 (`howItWorks.*`), MeetTheTeam callout (`team.assignmentNote`). Three occurrences on the homepage — reinforces the commitment without appearing repetitive (different section contexts).

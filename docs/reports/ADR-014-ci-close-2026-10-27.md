# ADR-014 Close Report — CI Gates Scoped to What Changed

**Closed:** 2026-10-27 · **Decision:** [`ADR-014`](../decisions/ADR-014-ci-gates-scoped.md) · **Plan:** [`ADR-014-ci_PLAN.md`](../plans/ADR-014-ci_PLAN.md)

## What changed
| Workflow | Change |
|---|---|
| `firebase-preview.yml` (PRs) | Removed the E2E job. Added lint to customer and FSM. New `rules` job (emulator) when rules or their tests change. `ci` filter now matches only this file. `firebase.json` now in the functions filter. |
| `firebase-deploy.yml` (main) | Removed the three `npm audit` steps. `ci` filter now matches only this file. `firebase.json` now in the functions filter. |
| `e2e.yml` (new) | Playwright, Mondays 09:17 UTC plus manual runs. No `continue-on-error`, so red means real failures. |
| `security-audit.yml` (new) | Daily 06:41 UTC plus manual runs. Audits root and `functions/` production dependencies, and opens or updates one issue on failure. |
| `docs-check.yml` | `push` limited to `main`. `user-guide/**` is now triggered and checked. |
| `codeql.yml` | PRs that change only docs or markdown are skipped. |

## 📋 Deliverables & Implementation Details

1.  **Real-Time Data Integration:**
    *   Added the `subscribeToBookings` subscription helper in [firestore.ts](file:///workspaces/fresh_nest/src/lib/firestore.ts) to establish a real-time Firestore database connection to the `bookings` collection.
    *   Ensured Firestore `Timestamp` objects are converted to JS `Date` objects safely, using `new Date()` as fallback.

2.  **Filtering, Sorting & Search Controls:**
    *   **Status Filter:** Allows filtering by *Pending*, *Confirmed*, *Completed*, or *Cancelled*.
    *   **Service Filter:** Filters bookings by standard service types (*Standard*, *Deep*, *Move-out*, *Post-construction*, *Airbnb*, *Commercial*).
    *   **Language Filter:** Filters bookings based on the client's booking language (*English*, *Français*).
    *   **Sorting Controls:** Supports sorting by preferred service date or submitted date, in ascending or descending order.
    *   **Search Input:** Implemented real-time fuzzy search matching on client full name, email, phone number, and service address.

3.  **Collapsible Rows & Details Panel:**
    *   Clicking a row expands a detailed view showing property specifications (bedrooms, bathrooms, square footage), pets present, marketing lead source, special instructions/notes, submitted timestamp, and requested add-ons.
    *   Displays workflow tags like *Airbnb Turnover Checklist* or *Photo Confirmation Required* depending on the service category.

4.  **Operational Operations (Status & Assignment updates):**
    *   Wired dropdowns to update a booking's status (`updateBookingStatus`) and assigned cleaner (`updateBookingAssignment`) in real-time.
    *   Added support for custom cleaner assignments using an inline text input when selecting "Custom / Other...".

5.  **Bilingual Compliance:**
    *   All labels, controls, text details, and page SEO metadata are translated using the `t()` hook.
    *   Added translations for new admin elements to both [en.json](file:///workspaces/fresh_nest/src/i18n/locales/en.json) and [fr.json](file:///workspaces/fresh_nest/src/i18n/locales/fr.json).

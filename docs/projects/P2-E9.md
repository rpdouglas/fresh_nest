# Project Spec: P2-E9 FSM Dispatch Board & Scheduling Intelligence

## Objective
Replace the text-based dropdown cleaner assignment model with a visual drag-and-drop dispatch board that checks cleaner availability, flags conflicts, and tracks earnings limits.

## Background
As cleaner staff count increases, matching cleaners to shifts manually becomes difficult. Admins need a visual dashboard to manage cleaner schedules, track earnings caps, and handle conflicts.

## Personas Served
- **Admin Operations (Lauren):** Needs efficient dispatch tools.
- **P6 Gallagher (Airbnb):** Relies on cleaners arriving on time during the 11am-3pm window.
- **Cleaners:** Benefit from well-spaced shifts within their monthly earnings limits.

## Key Tasks
- Build a visual dispatcher dashboard in `apps/customer/src/pages/AdminPage.tsx` using `@dnd-kit` (columns = active staff, rows = schedule grid).
- Build scheduling conflict detection engine:
  - Checks if cleaner is already assigned to a shift during that window.
  - Checks if booking address requires transit times violating cleaner buffers.
- Integrate conflict alerts:
  - Display warning inline on drag-and-drop or admin booking creation modal.
  - If overridden, require a reason. Save override event and description to the `auditLog` collection.
- Render weekly hours vs cleaner monthly earnings caps in the dispatch view.

## Acceptance Criteria
- Admin can drag a job card to a staff column to assign them.
- Conflicting schedules display a visual warning in the dashboard.
- Overrides require a reason, which is logged to the `auditLog` with decider details.

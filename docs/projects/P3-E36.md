## Owner decisions (2026-10-27)
1. **Permissions:** **Owners** can edit and save policy settings; **Managers** can view the **Settings & Policies** tab in read-only mode so they always see the active operational rules.
2. **Write path & version history:** Updates go through a server-checked Cloud Function callable (`updatePolicySettings`) that:
   - verifies the caller is an **Owner**;
   - validates the payload with the shared Zod schema (`PolicySettingsInputSchema`);
   - increments `version` (`1, 2, 3…`) on `settings/policy`;
   - writes an append-only version snapshot to `settings/policy/history/{version}` containing the full snapshot, changed fields (`before` / `after`), `changedBy`, `changedAt`, and optional `reason`;
   - records an `auditLog` entry (`collection: 'settings'`, `documentId: 'policy'`, `overrideType: 'policy_change'`).
3. **Read access in `firestore.rules`:**
   - `settings/policy` is readable by all staff and office roles (`isStaff()`) so both the Admin Portal and the FSM Staff App can read active policy values (with safe fallback defaults (`DEFAULT_POLICY_SETTINGS`) when the document has not been written yet).
   - `settings/policy/history/{version}` is readable by office roles (`isOffice()`).
   - Direct client writes to `settings/**` are denied (`allow write: if false`).
4. **Four policy sections & live wiring:**
   - **Section 1 — Scheduling & Travel Buffers** (wired live into `resolveBufferMinutes`, Admin Dispatch eligibility, and Cloud Functions `claimJob` / `listOpenShifts`):
     - `defaultVehicleBufferMinutes` (default `30`)
     - `defaultTransitBufferMinutes` (default `60`)
     - `baseDriveBufferMinutes` (default `10`)
     - `maxHoursPerDay` (default `10`)
     - `rollingScheduleWeeks` (default `8`)
     - `scheduleFreezeDays` (default `7`)
     - `undoWindowMinutes` (default `15`)
     - `swapNoticeHours` (default `12`)
   - **Section 2 — Staff Earnings, Time & Attendance** (wired live into `RegisterStaffModal` default ODSP cap & FSM `ProfilePage` ODSP caution band):
     - `defaultOdspMonthlyLimit` (default `1000`)
     - `earningsCautionThreshold` (default `100`)
     - `vacationNoticeDays` (default `14`)
     - `maxConcurrentOff` (default `2`)
     - `checkInGeofenceMeters` (default `250`)
     - `timesheetVarianceMinutes` (default `15`)
   - **Section 3 — Client Policies & Fees:**
     - `standardCancelWindowHours` (default `24`)
     - `deepCancelWindowHours` (default `48`)
     - `complaintWindowHours` (default `24`)
     - `lateCancellationFeeDollars` (default `0`)
     - `lockoutFeeDollars` (default `0`)
   - **Section 4 — Compliance, Retention & Emergency Contacts:**
     - `photoRetentionDays` (default `90`)
     - `agreementRetentionYears` (default `7`)
     - `emergencyPrimaryPhone` (default `"(613) 861-8812"`)
     - `emergencyBackupName` (default `""`)
     - `emergencyBackupPhone` (default `""`)

## Acceptance criteria / persona tests
1. **Exit criterion (W0-2 — "A setting changes behaviour without a release"):**
   - Changing `defaultVehicleBufferMinutes` or `defaultTransitBufferMinutes` in `settings/policy` changes the travel conflict threshold in `resolveBufferMinutes` (used by Admin Dispatch `checkCleanerEligibility`, `claimJob`, and `listOpenShifts`) without a code change.
   - Changing `defaultOdspMonthlyLimit` or `earningsCautionThreshold` updates the default ODSP limit in `RegisterStaffModal` and the caution gauge threshold in FSM `ProfilePage`.
2. **Owner vs Manager permissions:**
   - **Owner (P12 Lauren):** Can edit fields in the **Settings** tab, enter an optional change note, click **Save Settings**, and see the new version appear immediately in the **Version History** list.
   - **Manager:** Sees the **Settings** tab and **Version History** in read-only mode (inputs disabled, Save button replaced with a read-only notice), and the `updatePolicySettings` callable rejects non-Owner callers with `permission-denied`.
3. **Rules tests:**
   - `owner`, `manager`, `supervisor`, and `staff` can read `settings/policy`; `customer` and unauthenticated users cannot.
   - `owner` and `manager` can read `settings/policy/history/{version}`; `staff`, `supervisor`, and `customer` cannot.
   - No client role can write to `settings/policy` or `settings/policy/history/{version}` directly.
4. **Bilingual & Accessibility:**
   - Every label, description, section header, and history message is in both `en.json` and `fr.json` via `t()`.
   - Minimum 16px (`text-base`) text and 48px (`min-h-[48px]`) tap targets throughout `SettingsTab.tsx`.

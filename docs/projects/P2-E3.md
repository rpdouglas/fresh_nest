# Project Spec: P2-E3 "On My Way" Customer Notification

## Objective
Automatically send an SMS notification to the customer when their assigned cleaner checks in to a job.

## Background
Providing real-time updates reduces customer anxiety about arrival windows and establishes a premium level of service communication common in modern field service platforms.

## Personas Served
- **P2 Travis McLeod:** Values speed, mobile updates, and transparency.
- **P6 Gallagher (Airbnb):** Operates on tight, strict turnarounds and needs immediate check-in notification.

## Key Tasks
- Extend `onJobUpdatedTrigger` in `functions/src/index.ts`.
- Listen for status change `acknowledged` or `assigned` -> `in_progress` (specifically when `checkedInAt` changes from null to a valid timestamp).
- Check the booking language on the parent booking.
- Fetch the Twilio keys and client.
- Dispatch SMS to the customer's phone number using the localized template:
  - **EN:** *"Fresh Nest Co.: Your cleaner {cleanerName} is on the way! Estimated arrival is near your scheduled start window. (613) 935-3555"*
  - **FR:** *"Fresh Nest Co. : Votre préposé(e) {cleanerName} est en route ! Arrivée prévue près de votre plage de début programmée. (613) 935-3555"*
- Ensure checks are in place to prevent duplicate SMS runs for a single job check-in.

## Acceptance Criteria
- SMS is dispatched immediately when the cleaner checks in.
- The notification is received in the correct language (EN/FR matching the booking).
- No message is sent if the job is cancelled or if the cleaner checks out.

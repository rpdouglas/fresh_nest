# P3-E7 — Cloud Functions Bug Fixes

## Objective
Fix four production bugs in `functions/src/index.ts` that cause runtime crashes, type unsafety, and unnecessary Firestore reads.

## Personas
- All personas (reliability baseline — all bookings flow through Cloud Functions)

## Key Tasks
1. Replace `require()` calls with module-scope ESM `import` for stripe and twilio
2. Fix `as any` type cast on bookings query chain with proper typed variable
3. Remove double Firestore read (aggregation + manual loop) — use aggregation result
4. Replace `auditLogs: any[]` with a typed `AuditLogEntry` local type

## Acceptance Criteria
- `npm run build` in `functions/` produces zero TypeScript errors
- No `require()` calls remain in `functions/src/index.ts`
- No `any` type annotations in the four patched functions
- Stripe initialized from module-scope import (not dynamic require)

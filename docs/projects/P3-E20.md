# P3-E20 — Firebase App Check

## Objective
Enable Firebase App Check with ReCaptchaV3 on both customer and FSM apps to block unauthorized API access.

## Personas
- P3 Margaret, P4 Kahnawà:ke (data protection — booking data only accessible from legit app clients)

## Key Tasks
1. Add `VITE_RECAPTCHA_SITE_KEY` to both apps' vite-env.d.ts
2. Add conditional `initializeAppCheck` call to customer firebase.ts
3. Add conditional `initializeAppCheck` call to FSM firebase.ts
4. Both calls guard on env var presence (dev builds without key degrade gracefully)
5. **Manual operator step:** Enable App Check enforcement in Firebase Console for Firestore and Cloud Functions

## Manual Operator Step (Required Before Go-Live)
1. Go to Firebase Console → App Check → Apps
2. Register both apps (customer + FSM) with their respective ReCaptcha V3 site keys
3. Enable enforcement on: Firestore, Cloud Functions, Storage
4. Add `VITE_RECAPTCHA_SITE_KEY` to both Hosting environment configs

## Acceptance Criteria
- `initializeAppCheck` call present in both firebase.ts files
- Import is conditional on `VITE_RECAPTCHA_SITE_KEY` being set (dev-safe)
- Both apps build with zero TypeScript errors

## Schema Changes
None.

## Dependencies
None (App Check is standalone — no P3-E1 Stripe dependency).

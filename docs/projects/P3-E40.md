# P3-E40 — Sales Pipeline: Lead Ownership, Lifecycle & Follow-up

**Type:** Admin operations / sales · **Priority:** P1 · **Complexity:** L
**Opened:** 2026-11-23 · **Status:** 🔄 Phase A — Planning
**Plan:** [`plans/P3-E40_PLAN.md`](../plans/P3-E40_PLAN.md)
**Source:** Sales pipeline review report (Claude Doc, 2026-11-23): code audit + comparison with Jobber, Housecall Pro, Pipedrive and HubSpot
**Relationship:** The front half of **P3-E26 Quote-First Booking System** (lead → quote → won/lost). P3-E26 keeps quote documents, e-signing and deposits. Closes follow-up **F11** (record quoted price, quote sent/accepted).

## Problem
A quote request is a `bookings` document with `status: 'pending'`. It has no owner, no sales stage, no follow-up date and no won/lost record. `assignedTo` holds the cleaner's name, so it cannot carry lead ownership. New-request alerts go to a single `OWNER_EMAIL` / `OWNER_PHONE`, so the Manager is never alerted. The Bookings tab sorts by service date, which hides old, un-contacted requests.

## Owner decisions (2026-11-23)
1. **Default owner:** every new lead is assigned to **Lauren** (Owner). Kept as a setting so it can change without a release.
2. **Who can own a lead:** people with the roles **owner, manager, cleaner, supervisor, contractor**. Ryan is the Manager.
   - Supersedes the earlier same-day answer "office users only for now".
   - `owner` / `manager` = office users (`admins` list). `cleaner` / `supervisor` = `staff.role`. **`contractor` does not exist anywhere in the system today** (see open question Q1).
3. **First-contact targets:** **2 hours** for a cleaning request; **1 hour** for a request that needs an **in-person quote** (site visit). *Interpretation recorded by the agent; confirm in plan approval (Q3).*
4. **P16 Ryan · Office Manager** added to `PERSONAS.md` (v4.4, human-authorised).

## Scope
- Sales stage on each lead, separate from the booking `status`: **New → Contacted → Site visit (optional) → Quote sent → Won / Lost**
- One owner per lead (or unassigned); reassign with an alert to the new owner; every change audited (P3-E37)
- Next follow-up date on every open lead; overdue and age indicators against the targets above
- Required lost reason from a fixed list; Won confirms the booking (existing Dispatch flow)
- Contact log (calls, texts, emails, notes) on the lead
- Quote record: quoted amount (integer cents, ADR-020) and sent date — internal only, never public (P3-E29)
- "My leads", "Unassigned" and "All" views in the admin portal; a way for non-office owners (cleaner, supervisor, contractor) to see and work their assigned leads
- Pipeline card in Analytics: open leads by stage, time to first contact, conversion by source and owner, lost reasons
- Back-fill existing bookings into stages

## Out of scope
- Automated client follow-up SMS/email cadences (needs CASL wording first — phase 3 of the report)
- Quote documents, e-signing, deposits (P3-E26)
- Lead scoring, custom pipelines, email sequences

# P3-E4 — Observability & Error Tracking *(Carried from P1-E7)*

## Objective
Establish production observability. Cloud Function failures are currently silent — no alerting, no error tracking, no uptime monitoring.

## Personas
All — reliability foundation. Operator/CTO primary.

## Key Tasks

### Sentry (scaffolded — awaiting DSN secret)
1. Install `@sentry/react` in `apps/customer` and `apps/fsm`
2. Install `@sentry/node` in `functions/`
3. Initialize Sentry in both apps — gated on `VITE_SENTRY_DSN` env var (production only)
   - `BrowserTracing` integration
   - `Replay` integration with PIPEDA-compliant masking:
     - `maskAllInputs: true`, `blockAllMedia: false`
     - `replaysSessionSampleRate: 0.1`, `replaysOnErrorSampleRate: 1.0`
     - Network request/response bodies blocked
4. Add Sentry `sourceMap` upload step to `.github/workflows/firebase-deploy.yml` — skips gracefully when `SENTRY_AUTH_TOKEN` secret absent
5. Wrap all Cloud Function handlers in `Sentry.captureException()` in `functions/src/index.ts`
6. Add `VITE_SENTRY_DSN?: string` to both `vite-env.d.ts` files

### Cloud Logging
7. Replace all `console.error()` in `functions/src/index.ts` with structured JSON entries readable by Google Cloud Logging

### Firebase Performance
8. Add `getPerformance(app)` to `apps/customer/src/main.tsx`

### Manual operator steps (documented in close report, not automated)
- Add `VITE_SENTRY_DSN` and `SENTRY_AUTH_TOKEN` as GitHub Secrets when Sentry account is ready
- Create Google Cloud Monitoring alert policy: Function error rate > 2 in 5 min → email + SMS
- Configure UptimeRobot on `https://freshnest.ca`

## PIPEDA Compliance
Sentry Replay: `maskAllInputs: true` ensures no form field values (name, address, phone, postal code) are captured. Network request/response bodies blocked. Satisfies PIPEDA purpose-limitation and Quebec Law 25 requirements.

## Acceptance Criteria
- Sentry packages installed; initialization in both app `main.tsx` files, gated on `VITE_SENTRY_DSN`
- Replay configured with `maskAllInputs: true` and network body blocking
- Source-map CI step present in `firebase-deploy.yml` (skips if token absent)
- Zero `console.error()` remaining in `functions/src/index.ts`
- `getPerformance(app)` present in customer `main.tsx`
- Manual operator steps documented in close report
- `npm run build` passes with zero errors

## Schema Changes
None.

P1-E1 complete (clean secrets — DSN must not be hardcoded). ✅

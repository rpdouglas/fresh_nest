# P3-E27-B1 — Automated Welcome Email with Magic Link

## Parent Epic
- **P3-E27**: Employee Onboarding System

## Objective
Send a branded, bilingual welcome email to a new employee immediately when the administrator (Lauren) registers them. The email contains an embedded, passwordless Firebase Auth magic link that redirects to the FSM login screen with onboarding parameters to trigger the first-login sequence.

## Personas
- **P12 Lauren Arsenault (Admin/Owner)**: Saves time by automating registration communications instead of manually calling/texting credentials. Can monitor invitation status and trigger resends directly from the staff directory table.
- **P8 Jasmine Beausoleil (Cleaner)**: Receives a clear invitation email immediately, containing a simple CTA to log in without needing to invent or remember a password.
- **P11 Brenda Côté (Lead Cleaner - French Primary)**: Receives the registration email entirely in French according to her language preference set at registration.

## Key Tasks
1. **Extend `onStaffRegistered` Cloud Function**:
   - Retrieve `FSM_APP_URL` secret.
   - Generate Firebase Auth email sign-in link via `admin.auth().generateSignInWithEmailLink(email, actionCodeSettings)`.
   - Set redirect URL to `${FSM_APP_URL}/login?onboarding=true`.
   - Call `sendWelcomeEmail` with the selected language (`en` or `fr`), first name, and magic link URL.
   - Store `welcomeEmailSentAt: Timestamp.now()` in the `staff/{uid}` Firestore document.
2. **Create New Cloud Function `resendWelcomeEmail`**:
   - Accepts `{ uid }`.
   - Authorizes that the request context is an admin.
   - Retrieves the staff document to get the email and preferred language.
   - Generates a new magic link.
   - Sends the welcome email and updates `welcomeEmailSentAt` timestamp in Firestore.
   - Properly logs any email delivery failure to Sentry and throws an explicit HttpsError.
3. **Define Email Templates**:
   - Implement `staffWelcomeEn` and `staffWelcomeFr` in `functions/src/emailTemplates.ts`.
   - Use CSS styles that match the Fresh Nest Co. brand guidelines (slate-brand header, cream background, clean typography).
   - Email content: Personal greeting, explanation of onboarding requirements (Background Check and Terms acceptance on first login), CTA button pointing to magic link, Lauren's contact details, and brand footer.
4. **Update Shared Types & Firestore Converters**:
   - Add `welcomeEmailSentAt?: Date | null` to the `Staff` type in `packages/shared/src/types/staff.ts`.
   - Add parsing for `welcomeEmailSentAt` inside the centralized `staffConverter` in `packages/shared/src/firebase/converters.ts`.
5. **Update Admin Registry UI**:
   - Modify `apps/customer/src/components/admin/StaffTable.tsx` to display `welcomeEmailSentAt` date/time status in the "Contact" column.
   - Add a "Resend Invite" button in the "Actions" column that triggers `resendWelcomeEmail` with toast loading and success feedback.

## Acceptance Criteria
- [ ] Jasmine receives an invitation email immediately upon registration.
- [ ] Brenda receives the invitation email entirely in French.
- [ ] Magic link successfully signs the user into FSM with `onboarding=true` in the query params.
- [ ] The `staff` collection schema includes the `welcomeEmailSentAt` timestamp field, properly parsed into a Date by the shared converter.
- [ ] Admin panel displays the sent date or "Not Sent" in the staff row.
- [ ] Admin can click "Resend Invite" to trigger a fresh email with toast confirmation, logging errors to Sentry if delivery fails.
- [ ] Code builds cleanly and lint checks pass with zero errors.

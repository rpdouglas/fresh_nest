# Project Spec: P2-E1 Customer Account Portal

## Objective
Allow customers to create an account, view booking history, manage recurring subscription frequency, rebook a past service, and cancel an upcoming appointment.

## Background
Currently, there is no customer-facing authenticated experience. Every booking and cancellation requires either the public booking form or a phone call. To reduce administrative overhead and increase retention, a self-service customer portal is required.

## Personas Served
- **P1 Diane Lafleur:** Wants consistency, French language UX, and the ability to rebook without re-entering details.
- **P3 Margaret Storey:** Prefers simple self-service management for her cleaning schedule.

## Key Tasks
- Implement Firebase passwordless email link authentication (Magic-Link) and Google Sign-In.
- Automatically link customer accounts using email match during registration.
- Build portal navigation and views:
  - `/account/bookings` (View history, check status, assign ratings)
  - `/account/upcoming` (View, update recurrence frequency, or cancel upcoming cleanings)
  - `/account/profile` (Update billing profile, address, contact preferences)
- Build cancellation action:
  - Cloud function releases Stripe payment hold.
  - Updates booking status to `cancelled`.
  - Sends SMS alert to admin.
- Secure customer Firestore access:
  - Restrict query results to documents where `email == request.auth.token.email`.

## Acceptance Criteria
- Customer can log in without a password via email link.
- Upcoming and past cleanings load correctly in both English and French.
- Cancellation cancels the shift, releases Stripe hold, and alerts admin via SMS.
- No user can fetch or modify bookings belonging to another user's email.

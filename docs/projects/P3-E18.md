# P3-E18 — Shared Types Package

## Objective
Consolidate all Firestore entity types (Booking, Staff, Job, ChecklistTask) into `@freshnest/shared`, eliminating type drift between customer and FSM apps.

## Personas
- P2 Travis (booking accuracy), P6 Gallagher (job photo reliability)

## Key Tasks
1. Create `packages/shared/src/types/booking.ts` — canonical Booking, BookingStatus, etc.
2. Create `packages/shared/src/types/staff.ts` — canonical Staff, StaffRole, etc.
3. Create `packages/shared/src/types/job.ts` — canonical Job, JobPhoto (lat/lng)
4. Create `packages/shared/src/types/common.ts` — ChecklistTask (labelEn/labelFr), ChecklistTemplate
5. Re-export all from `packages/shared/src/index.ts`
6. Rewrite `apps/customer/src/types/index.ts` to re-export from shared
7. Rewrite `apps/fsm/src/types/index.ts` to re-export from shared
8. Fix FSM divergences: labelKey → labelEn/labelFr in JobPage.tsx; geoLat/geoLng → lat/lng in OfflineUploadProvider.tsx
9. Update JobPage.test.tsx mock data to match canonical types

## Type Divergence Resolutions
| Field | Old FSM | Old Customer | Canonical |
|---|---|---|---|
| ChecklistTask label | `labelKey: string` | `labelEn/labelFr: string` | `labelEn/labelFr: string` |
| JobPhoto geo | `geoLat/geoLng/geoTagged` | `lat?/lng?` | `lat?: number; lng?: number` |
| Job.id | required | optional | `id?: string` |
| Staff.uid | required | — | `uid?: string` |

## Acceptance Criteria
- Both apps build with zero TypeScript errors
- `apps/fsm/src/lib/utils/indexedDb.ts` QueuedPhoto retains geoLat/geoLng/geoTagged (IndexedDB-specific)
- No `any` type used in shared type files

## Schema Changes
None (types only — no Firestore schema change).

## Dependencies
None.

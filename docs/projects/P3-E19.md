# P3-E19 — Cloud Functions Domain Split

## Objective
Split the monolithic `functions/src/index.ts` (~1,480 lines, 19 exported functions) into domain-scoped modules. This improves code organization, unblocks upcoming Sprint 5/6 epics (such as P3-E27 onboarding and P3-E28 scheduling), and ensures each file adheres to the 200-line maximum limit.

## Personas
- **P12 Lauren** — Admin operations. Clean, modular backend code ensures rapid feature delivery and robust error tracking (via Sentry) for onboarding/dispatch.
- **P8 Jasmine / P11 Brenda / P14 Sylvie** — Cleaners and Field Staff. Uninterrupted notifications (SMS and Email) for job claims, schedule changes, and reminders.
- **P2 Travis** — Fast Booking. Booking triggers (referral code generation, job generation) must execute reliably with zero downtime.

## Key Tasks
1. **Create `lib/shared.ts` Bootstrap Module**:
   - Move `initializeApp()` and `Sentry.init(...)` here.
   - Define and export all environment secrets (`RESEND_API_KEY`, `OWNER_EMAIL`, `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER`).
   - Export standard Firebase service wrappers (`db`, `auth`) and helpers (`logError`).
2. **Move Trigger Functions (`triggers/`)**:
   - `triggers/booking.ts` (Booking creation, updates, and cancellations).
   - `triggers/job.created.ts` (Job creation triggers).
   - `triggers/job.updated.ts` (Job status changes, completions, claims).
   - `triggers/staff.ts` (Staff updates).
   - `triggers/auth.ts` (Firebase Auth v1 user creation).
3. **Move Callable Functions (`callable/`)**:
   - `callable/auth.ts` (Role setting).
   - `callable/payments.ts` (Stripe payment intents, webhook handlers).
   - `callable/job.ts` (Claiming a job).
   - `callable/analytics.ts` (Analytics KPIs).
   - `callable/staff.ts` (Staff registration, compliance migrations).
4. **Move Scheduled Cron Functions (`scheduled/`)**:
   - `scheduled/reminders.ts` (Daily booking reminder check).
   - `scheduled/renewals.ts` (Daily recurring service renewal check).
   - `scheduled/earnings.ts` (Monthly staff earnings rollover check).
   - `scheduled/reviews.ts` (Review email scheduler).
5. **Convert `index.ts` to Pure Re-Exports**:
   - Remove all logic, helper functions, and initializations.
   - Export all functions directly from their new domain modules.
6. **Lint & Build Verification**:
   - Ensure all relative imports inside `functions/` compile correctly.
   - Run `npm run build` and `npm run lint` in the `functions/` directory.

# Project Spec: P2-E5 Accessibility Pass (WCAG 2.1 AA)

## Objective
Establish full WCAG 2.1 AA accessibility compliance across the customer booking flows and admin panels.

## Background
Accessibility is both a legal requirement and an essential design choice for supporting older clients or those utilizing assistive technologies.

## Personas Served
- **P3 Margaret Storey:** Focuses on accessibility (needs high contrast, legible font size, and clear tap targets).

## Key Tasks
- Implement a "Skip to main content" layout link:
  - `<a href="#main-content" className="sr-only focus:not-sr-only">Skip to content</a>`
- Update mobile navigation toggles with correct screen reader states (`aria-expanded`, `aria-controls`).
- Set up active focus management in multi-step forms:
  - When the user transitions between steps, programmatically shift focus to the first header or input of the new step.
- Verify text contrast and sizing:
  - Ensure body text sizing is at least `16px` (`text-base`).
  - Eliminate all contrast ratios lower than 4.5:1 for body copy.
- Enforce touch target rules:
  - Ensure all interactive elements have tap target dimensions of at least `48px` by `48px`.
- Bind html `lang` attribute dynamically to the selected language (`en`/`fr`).

## Acceptance Criteria
- Lighthouse accessibility score of $\ge 90$ on home and booking pages.
- Keyboard-only navigation allows complete flow execution without a mouse.
- No critical or serious violations reported in axe-core automated audits.

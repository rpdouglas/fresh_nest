# Project Spec: P2-E7 PWA Configuration

## Objective
Configure the customer app as an installable Progressive Web App (PWA) with static asset caching and offline support.

## Background
Providing a web app shell that functions offline or on spotty connections helps mobile users book services quickly and allows cleaners to access schedules in transit.

## Personas Served
- **P2 Travis McLeod:** Mobile-first, on-the-go customer seeking app-like access.
- **FSM Staff Cleaners:** Need offline access to job locations and details when network connectivity is poor.

## Key Tasks
- Register and configure `vite-plugin-pwa` in `apps/customer/vite.config.ts`.
- Set cache strategies in the Service Worker:
  - `CacheFirst` for JS, CSS, fonts, and images.
  - `NetworkFirst` for dynamic Firestore queries.
- Build a custom install banner:
  - Intercept the `beforeinstallprompt` event.
  - Display a subtle, non-intrusive banner prompting install.
- Validate service worker lifecycle behavior across iOS Safari and Android Chrome.

## Acceptance Criteria
- Lighthouse PWA compliance checks pass completely.
- Offline mode allows the booking shell and profile page to load.
- Cleaner job sheets are readable without an active network connection (uses `persistentLocalCache`).
